# Раздел «Пользователи»

## Назначение

URL: `/rights/users/`. Доступен только администраторам.

## Список

Поддерживает:

- поиск по логину и ФИО;
- фильтр роли, статуса, сервиса и архива;
- сортировку;
- 25/50/100 строк;
- полный список назначенных сервисов;
- клик по всей строке и action menu.

## Создание пользователя

Обязательны логин, ФИО и временный пароль. Можно сразу назначить роль и сервисы.
Кнопка генерации создаёт пароль локально через Web Crypto и заполняет оба поля;
пароль сохраняется только после submit формы.

## «Основное»

- логин;
- ФИО;
- active-state;
- роль администратора;
- последний вход;
- дата установки пароля.

После создания логин/ФИО меняет только администратор. Новый администратор получает
те же admin-разделы и полный каталог.

## «Доступы»

Обычному пользователю назначаются карточки сервисов. Для администратора выбор
не ограничивает доступ: он всегда видит весь каталог.

## «Безопасность»

- временный пароль;
- персональные IP/CIDR;
- показать/отозвать/ротировать token;
- потребовать смену пароля;
- снять блокировку авторизации.

Пустой персональный CIDR означает отсутствие дополнительного ограничения, но
глобальный allowlist HUB продолжает действовать.

## «Сессии»

Администратор видит активные sessions пользователя и может завершить одну или
все. Завершение происходит server-side и не зависит от закрытия вкладки.

## «Аудит»

Показывает последние нормализованные события конкретного пользователя.

## Токены

- `Создать` — первый token;
- `Показать` — раскрыть существующий зашифрованный token;
- `Ротировать` — выпустить новый и немедленно отменить старый;
- `Отозвать` — удалить возможность входа по token.

Token показывается в модальном окне и копируется по явному действию. Не отправляйте
его в общие чаты и тикеты.

## Архив и восстановление

`Архивировать` — мягкое удаление: ставит `deleted_at`, отключает учётку,
завершает sessions и отзывает token. Аудит сохраняется.

Фильтр архива позволяет найти запись и выполнить `Разархивировать`. После
восстановления проверьте active-state, пароль, права, персональные CIDR и token.
