# Авторизация и первый вход

## Страница `/`

Корневой URL HUB используется как страница входа. Старый `/login/` перенаправляет
на `/` без сохранения лишнего query string.

Доступны два режима:

- `Учётная запись` — логин и пароль;
- `Токен` — постоянный login token, выпущенный администратором.

Кнопка `Войти` активируется только после заполнения обязательных полей. Глаз в
поле пароля/token меняет видимость значения, но не отправляет его на сервер.

## Порядок проверки логина и пароля

1. Глобальный CIDR допускает IP к форме входа.
2. Проверяется server-side browser lock.
3. Находится активная неархивная учётная запись.
4. Проверяется персональный CIDR пользователя.
5. Проверяется Argon2id password hash.
6. При успехе создаётся серверная сессия на 24 часа.
7. При временном пароле открывается обязательная смена.
8. Иначе выполняется переход в `/services/` или к исходному сервису.

## Вход по токену

Token работает как альтернативный метод входа в ту же учётную запись. Он:

- не является одноразовым;
- действует до ротации или отзыва;
- не отменяет active-state, CIDR и права пользователя;
- не расходует password-attempt counter;
- создаёт обычную серверную сессию на 24 часа.

## Ошибки входа

- пустые поля не отправляются;
- неверные данные дают нейтральное сообщение `Мы вас не узнаем`;
- при превышении лимита показывается время блокировки;
- неверный вход временно переводит particle-фон в тревожный режим;
- при глобальном IP deny форма входа вообще не отображается.

Ответ не должен раскрывать, существует ли введённый логин. Это уменьшает
возможность перебора учётных записей.

## Первый вход и временный пароль

Администратор может создать временный пароль или включить `Потребовать смену
пароля`. После успешного входа пользователь видит компактную форму `Укажите новый
пароль`. Доступ к каталогу и reverse proxy до успешной смены блокируется.

## Сессия

- хранится в MariaDB;
- cookie сохраняется после закрытия браузера;
- срок — 86400 секунд от момента входа;
- активность не продлевает срок;
- logout завершает текущую сессию;
- администратор может завершить сессии пользователя.

## Безопасный переход с прямого URL сервиса

Если пользователь открыл service-domain без сессии, HUB создаёт краткоживущее
server-side redirect state. После входа пользователь возвращается к разрешённому
сервису без передачи произвольного `next` URL в адресной строке.

## Particle-фон

Canvas работает только на странице входа и IP-block page. Он не принимает клики,
останавливается в неактивной вкладке и учитывает `prefers-reduced-motion`.
Параметры задаются администратором в разделе `Визуал`.
