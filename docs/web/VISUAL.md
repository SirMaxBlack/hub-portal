# Раздел «Визуал»

## Назначение

URL: `/visual/`. Открывается администратором по кнопке-шестерёнке.

Настройки применяются ко всем пользователям на страницах входа и блокировки по
глобальному IP/CIDR. После авторизации particle canvas не загружается.

## Параметры

- число particles desktop для входа;
- число particles desktop для IP-block;
- число particles mobile для входа;
- число particles mobile для IP-block;
- скорость спокойного состояния в px/sec;
- скорость тревожного состояния в px/sec;
- длительность тревоги при неверном входе;
- длительность тревоги при lockout;
- длительность плавного затухания.

Нулевые значения запрещены. Верхние пределы формы защищают browser от случайной
чрезмерной нагрузки.

## Состояния анимации

- спокойное — сине-белые particles;
- неверный логин/password/token — короткое плавное покраснение и ускорение;
- превышение лимита — более длительная тревога;
- IP-block — постоянные красные particles и бело-красные линии.

При переходе между состояниями particles не пересоздаются и не меняют позицию
скачком: меняются скорость и цвет текущих объектов.

## Производительность

- canvas ограничивает FPS;
- device pixel ratio ограничен;
- вкладка на паузе при `visibilitychange`;
- canvas не перехватывает pointer events;
- на mobile используется отдельное меньшее количество particles;
- `prefers-reduced-motion` отключает движение или оставляет статичный fallback.

Если анимации нет только на одном компьютере, проверьте системную настройку
анимаций и `prefers-reduced-motion` в браузере/ОС.

## Рекомендации

Начинайте с умеренных значений. После увеличения количества проверьте CPU/GPU в
Chrome, Firefox и Edge, а также ввод текста на слабом mobile. Визуальный эффект
не должен задерживать отправку формы.
