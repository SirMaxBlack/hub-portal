## Общие правила интерфейса

- активный пункт верхнего меню подсвечивается;
- шестерёнка открывает настройки визуала;
- солнце/луна меняет тему в browser local storage;
- опасные действия требуют отдельного подтверждения;
- toast-уведомления показываются поверх модальных окон;
- на ширине меньше 1024 px верхнее меню открывается как drawer;
- формы имеют CSRF-защиту, а JSON actions доступны только авторизованным ролям;
- admin-only кнопку недостаточно скрыть CSS: backend также проверяет роль.

## Статусы сервисов

- зелёный — `up`, сервис подтверждённо доступен;
- красный — `down`, открытие блокируется;
- нейтральный — `unknown`, свежего подтверждения ещё нет.

Статусы обновляются в фоне без полной перезагрузки страницы.

## Термины

- **Администратор** — пользователь с `is_staff`, видит все сервисы и admin-разделы.
- **Пользователь** — видит только назначенные сервисы.
- **Reverse proxy** — запрос проходит через nginx HUB к внутреннему upstream.
- **Внешняя ссылка** — обычный redirect; дальнейший трафик не идёт через HUB.
- **Токен входа** — постоянный буквенно-цифровой secret пользователя, не API key
  downstream-сервиса.
